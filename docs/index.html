Attivazione "Ehi Siri" (Sideloadly Free ID) URL SCHEME ATTIVO

Con Sideloadly su Apple ID gratuito, DoomAi usa il protocollo diretto doomai:// per far funzionare "Ehi Siri" tramite l'app Comandi Rapidi di iPhone.

CONFIGURAZIONE IN 20 SECONDI
Come attivare "Ehi Siri, Chiedi a Doom"
1. Tocca "Apri Comandi Rapidi & Copia URL" qui sotto.
2. In Comandi Rapidi tocca + e chiamalo "Chiedi a Doom".
3. Aggiungi "Apri URL" con doomai://voice (ascolto vocale immediato) oppure "Chiedi input" + doomai://ask?q= + Input fornito.
// URL Scheme Registrati:
// doomai://voice         -> Avvia subito il microfono di DoomAi
// doomai://ask?q=Domanda -> Esegue e legge la risposta ad alta voce
